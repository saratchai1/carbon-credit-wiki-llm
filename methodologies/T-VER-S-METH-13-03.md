# T-VER-S-METH-13-03 v01

**การปลูกป่าอย่างยั่งยืนโครงการขนาดใหญ่ / Large Scale Sustainable Forestation Project**

## Wiki use

This methodology is recorded because the registered Standard T-VER Group 2 mangrove project was validated/registered using `T-VER-S-METH-13-03` version 01 together with `T-VER-S-TOOL-01-01` version 01.

It is a **project-specific historical methodology lock**, not the Wiki default current methodology. Do not replace [[../standards/current-standard]] with this page and do not assume this version is currently open for a new 2026 project without checking TGO.

## Group 2 implementation notes

For [[../projects/standard-tver-group-2/README]] the registered design:
- includes aboveground and belowground tree biomass;
- excludes SOC, deadwood and litter;
- uses Komiyama et al. (2005) mangrove equations described in the project PDD;
- treats project emissions as zero based on no burning/no site-preparation machinery in the PDD;
- treats leakage as zero based on non-agricultural/non-agroforestry land-use conditions in the PDD;
- uses a 10-year crediting period from 15 Nov 2023 to 14 Nov 2033.
