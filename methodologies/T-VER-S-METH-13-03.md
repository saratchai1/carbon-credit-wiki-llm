# T-VER-S-METH-13-03 v01

**การปลูกป่าอย่างยั่งยืนโครงการขนาดใหญ่ / Large Scale Sustainable Forestation Project**

## Wiki use

This methodology is recorded because multiple registered Standard T-VER mangrove projects in the Wiki were validated/registered using `T-VER-S-METH-13-03` version 01 together with `T-VER-S-TOOL-01-01` version 01.

It is a **project-specific historical methodology lock**, not the Wiki default current methodology. Do not replace [[../standards/current-standard]] with this page and do not assume this version is currently open for a new 2026 project without checking TGO.

## Critical multi-project rule

Sharing a methodology code/version does **not** make project parameters interchangeable. The Wiki currently contains two distinct Standard T-VER projects that both use “Group 2” wording:

### A. `STC-STANDARD-TVER-GROUP-2`

See [[../projects/standard-tver-group-2/README]].

Registered design summary:
- 50 plots / 9,005.55 rai
- crediting period 15 Nov 2023 – 14 Nov 2033
- registered expected quantity 84,652 tCO2eq/year
- project-specific pool/emission/leakage configuration documented in its project folder

### B. `STC-VSD-STANDARD-TVER-GROUP-2`

See [[../projects/standard-tver-group-2-stc-vsd/README]].

Registered design summary:
- 22 plots / 6,775.53 rai
- crediting period 31 May 2024 – 30 May 2034
- registered expected quantity 63,689 tCO2eq/year
- baseline tree carbon stock 362,962.8144 tCO2eq
- Landsat-8/FCD coast × canopy-density stratification

**Never copy area, boundary, baseline, carbon-pool selection, emissions/leakage assumptions, monitoring dates or expected quantities from one project to the other.**

## Generic methodology reference from project evidence

The STC+VSD project's validated PDD shows the general carbon-stock forms:

`C_BS = C_TT0 + C_Dead0 + C_Litter0 + SOC_0`

`C_PS,t = C_TT,t + C_Dead,t + C_Litter,t + SOC_t`

These general equations do not prove that every pool is selected or non-zero in every project. Use each project's PDD/profile for pool inclusion.
