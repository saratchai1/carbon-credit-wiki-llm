# Eligibility Checklist

ใช้ก่อนเริ่ม calculation.

| Check | Required evidence | Status |
|---|---|---|
| Methodology fit: mangrove A/R | project activity description | ☐ |
| Legal land-use right | deed/permit/official right document | ☐ |
| Baseline is not forest | historical imagery + analysis | ☐ |
| Baseline canopy threshold met | canopy evidence | ☐ |
| Mangrove species >90% area | planting/species plan | ☐ |
| Hydrology condition satisfied | design/field evidence | ☐ |
| Project start date known | planting/seeding record | ☐ |
| Additionality assessed | TGO tool/PDD evidence | ☐ |
| Soil disturbance condition | activity map/log | ☐ |
| Project boundary fixed | GIS polygon | ☐ |
| Carbon pools selected | PDD/config | ☐ |
| Monitoring approach defined | MRV plan | ☐ |
| Non-permanence plan | risk assessment | ☐ |

ถ้าข้อที่เป็น applicability/condition ยังไม่ผ่าน ให้หยุดที่ `NOT_CALCULABLE` สำหรับเครดิตเชิงโครงการ.
