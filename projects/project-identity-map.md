## Disambiguation rule

Before using a project-specific number, resolve identity using at least one strong identifier:
1. exact Thai/English project title,
2. project/source ID prefix,
3. plot ID + province/boundary,
4. VVB/project-party combination,
5. explicit project-profile path.

Never merge plot lists, boundaries, calculations, source notes or VVB findings across the two packages merely because both say “Group 1”. No supersession relationship between these two project packages is established by the currently ingested evidence.
