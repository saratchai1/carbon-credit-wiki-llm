## MRV architecture

The project gives a useful registered precedent:

`Landsat-8/FCD → coast/FCD strata → sample plots → species/DBH → biomass → carbon → CO2eq → project aggregation`

FCD classes:
- high `>65%`
- medium `30–65%`
- low `<30%`

Sample plots:
- 40 × 40 m = 1 rai
- 20 × 40 m = 0.5 rai

Rhizophora POM rule in the PDD: if prop roots rise above the normal 1.30 m DBH point, measure diameter **30 cm above the prop-root point**.
