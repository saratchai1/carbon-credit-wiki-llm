## Reusable QC gates

### 1. Project boundary

Water/channel areas not participating in the carbon project must be excluded. Boundary revision must propagate into area-dependent baseline and project calculations.

### 2. GIS/PDD/workbook consistency

Reconcile:
- project boundary area
- sample-plot area
- sample-plot coordinates
- PDD tables
- calculation workbook

Do not accept a calculation where these disagree without a documented resolution.

### 3. Recalculation after area change

The validation identified baseline/project summary errors caused by incorrect project area. Any area revision requires dependent totals to be recalculated.

### 4. Tree tag ↔ species

Tag/species mapping must match field evidence. The validation identified mismatched tag/species records and required correction in the calculation workbook.

### 5. Species ↔ allometry

Do not retain species or species-specific equations merely because they exist in an earlier PDD/template. An earlier revision included Casuarina/สนทะเล treatment although field inspection did not find the species; both the species statement and related calculation treatment were challenged.

### 6. Botanical description

Species/growth-form descriptions must be consistent with field evidence.

### 7. Monitoring parameter alignment

PDD/MR monitoring parameters and frequencies must match the selected methodology/tool.
