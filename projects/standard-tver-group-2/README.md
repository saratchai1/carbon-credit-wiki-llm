# Registered Standard T-VER — Group 2

This folder is the project-specific methodology lock and evidence summary for the registered Standard T-VER mangrove project Group 2. It must not be mixed automatically with the Wiki default Premium T-VER methodology.

## Registered project identity

- Owner / developer: กรมทรัพยากรทางทะเลและชายฝั่ง (DMCR)
- Co-developer: บริษัท สยาม ทีซี เทคโนโลยี จำกัด
- Project form: bundled project
- Project plots: 50
- Project area: 9,005.55 rai
- Provinces: Ranong, Krabi, Phang Nga, Phuket, Satun, Samut Songkhram
- Crediting period: 15 Nov 2023 – 14 Nov 2033 (10 years)
- Registered methodology lock: `T-VER-S-METH-13-03` v01
- Calculation tool: `T-VER-S-TOOL-01-01` v01

## Registered ex-ante quantity

- Baseline tree sequestration/stock used in the workbook: **546,011.7485 tCO2eq**
- Project tree sequestration/stock at year 10: **1,392,533.4485 tCO2eq**
- Net project sequestration over 10 years: **846,521.70 tCO2eq**
- Average ex-ante quantity: **84,652.17 tCO2eq/year**
- Registration certificate rounds this to **84,652 tCO2eq/year**.

This is an **ex-ante registered/validated project estimate**, not evidence of issued credits. Under the Wiki output vocabulary, do not label it `CERTIFIED_CREDIT`, and do not label it `VERIFIED_RESULT` unless a monitoring Verification Report is available. For calculation use, treat it as `PROJECT_ESTIMATE` with strong registration/validation evidence.

## Carbon pools and accounting assumptions in the registered design

Included:
- aboveground tree biomass
- belowground tree biomass

Excluded:
- soil organic carbon (SOC)
- deadwood
- litter

The PDD states project emissions were not calculated because there was no burning and no machinery used for site preparation, and leakage was not calculated because the project area was not agricultural land and the project was not agroforestry.

## Evidence precedence for this project

When project documents disagree, use this order for the registered ex-ante quantity:

1. TGO registration certificate
2. Validation Report by Bureau Veritas Certification (Thailand)
3. validated/registered PDD and calculation workbook
4. supporting field/GIS files

A wording inconsistency exists in the PDD around `84,652 tCO2eq`. The certificate, Validation Report and calculation workbook resolve it as approximately **84,652 tCO2eq/year**, while **846,521.70 tCO2eq** is the 10-year net total.
