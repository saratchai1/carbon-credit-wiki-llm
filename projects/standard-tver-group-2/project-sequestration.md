## Interpretation

This is the registered ex-ante calculation, not a monitoring-period measurement and not TGO issuance evidence. Actual credits require monitoring, verification and issuance evidence according to the applicable program requirements.

## PDD assumptions to re-confirm during monitoring

The PDD sets project emissions to zero because it states:
- no burning in the project area
- no machinery for site preparation

Leakage is set to zero because it states:
- project land was not under agriculture
- project was not agroforestry

These are design assumptions/evidence statements. They should not be carried forward blindly if monitoring evidence later shows different activities.
