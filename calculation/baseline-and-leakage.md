# Baseline and Leakage

## Baseline

`ΔC_BSL,t = ΔC_TREE_BSL,t + ΔC_SAP_BSL,t + ΔC_DW_BSL,t`

ค่า baseline/change บางกรณีสามารถเป็น 0 ได้ **เฉพาะเมื่อเข้าเงื่อนไข tool**.

ห้ามตั้ง baseline = 0 เพียงเพราะพื้นที่ดูโล่งจากภาพปัจจุบัน.

หลักฐานที่ควรมี:
- historical satellite/aerial imagery
- land-use history
- crown cover
- pre-project trees
- documentary/PRA evidence ตาม tool

## Leakage

`LK_t = LK_AGR,t`

ใช้เมื่อ project activity ทำให้เกิด displacement ของ pre-project agricultural activity หรือทำให้เกิดการบุกรุก/ใช้พื้นที่ใหม่ที่เกี่ยวข้อง.

ถ้าไม่มี leakage:
- ต้องมี evidence/justification
- ไม่ใช่ใส่ 0 โดยไม่มี reason
