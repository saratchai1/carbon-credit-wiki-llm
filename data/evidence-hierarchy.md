# Evidence Hierarchy

| Tier | Evidence | Use |
|---|---|---|
| A | Current official TGO document/database | rule / formula / validity |
| B | Validated PDD / Verified MR / VVB report / TGO issuance | project-specific authoritative |
| C | Primary field/GIS/activity records | calculation input |
| D | Peer-reviewed study satisfying tool conditions | parameter/allometry |
| E | Calibrated remote-sensing/AI output | derived measurement/support |
| F | LLM inference | hypothesis only |

Numeric result inherits the weakest critical evidence tier unless methodology explicitly permits otherwise.
