# Field Measurement

## Minimum per tree

- project_id
- stratum_id
- sample_plot_id
- tree_id
- species_scientific
- species_thai
- measurement_date
- DBH_cm / diameter_cm
- height_m ถ้าสมการต้องใช้
- measurement_point_method
- allometry_id
- QA status
- recorder
- coordinate ถ้ามี

## Rhizophora

ใช้ measurement point ที่ 30 cm เหนือ highest prop root ตาม T-VER-P-TOOL-01-07 หรือเงื่อนไขของสมการที่เลือก.

## Plot

เก็บ:
- plot geometry
- plot area rai
- permanent/repeated plot flag
- stratum
- establishment method
- photos
- field form source

## QA

อย่างน้อย:
- impossible DBH
- duplicate tree_id
- wrong species/allometry mapping
- missing measurement point
- DBH outside allometry domain
- inconsistent unit
- t1/t2 plot mismatch
