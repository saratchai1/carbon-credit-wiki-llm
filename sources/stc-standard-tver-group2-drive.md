## Conflict handling

### Quantity wording

A PDD sentence is ambiguous and can read as if 84,652 tCO2eq were the 10-year total. The workbook, Validation Report and certificate resolve the registered interpretation:
- 84,652.17 tCO2eq/year = annual average
- 84,652 tCO2eq/year = certificate rounded value
- 846,521.70 tCO2eq = 10-year net total

### PDD copy identity

Validation evidence references PDD v2 dated 23 Jun 2024, while the source folder contains files named `V2(22-8-24)`. Status: `VERSION_IDENTITY_UNCONFIRMED` until direct comparison/hash evidence is recorded.
