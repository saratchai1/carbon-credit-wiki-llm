# Source Note — MOC1/STC Validation Report

## Scope

Independent validation evidence for PDD version 3 dated 2024-06-12.

## Claims extracted

- Project: โครงการฟื้นฟูป่าชายเลน เพื่อระบบนิเวศที่ยั่งยืนของประเทศไทย (กลุ่ม 1).
- Standard: Premium T-VER.
- Owner/developer: DMCR; co-developer: Siam TC Technology Co., Ltd.
- Methodology: T-VER-P-METH-13-02 v01.
- 19 plots, 8 provinces, project area 554.32 rai.
- Site classes include former aquaculture/shrimp ponds, cleared planting-ready areas and accreting mudflats.
- Project planting/maintenance described as 30 years.
- Crediting period: 15 years, 2023-10-01 to 2038-09-30.
- Ex-ante result: 86,085.90 tCO2e over 15 years; 5,739 tCO2e/year.
- Baseline assessed as zero; ex-ante leakage reported as zero.
- 9.4 tCO2e/rai/year Rhizophora increment accepted for the ex-ante calculation in the project package.
- Future carbon assessment approach: stratified random sampling and repeated measurements.
- Validation-stage baseline sample plots were not established because baseline was assessed as zero.
- DBH is identified as a material monitoring variable.
- Validation report references Komiyama et al. (2005) mangrove allometry and lists species wood-density values.

Validation opinion captured in the report: **Certify with Comment**, with the comment tied to the use of the 9.4 tCO2e/rai/year increment.

## Equations / parameters

The report quotes Komiyama-style biomass equations and wood densities. Exact equation transcription, exponent and valid parameter range must be checked against the source PDF/primary publication before being promoted to a production allometry registry entry.

- Bruguiera gymnorhiza: 0.699
- Avicennia marina: 0.65
- Excoecaria agallocha: 0.32
